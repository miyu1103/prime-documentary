## 3. コンテンツ選定ルール（データ検証済み）

すべての企画は次の1問に答える形にする（勝ってる3本の共通構造）:

> **「◯◯は、あなたに △△ できるのか？」** （◯◯=警察/政府/企業、△△=スマホを見る/家を奪う/追跡する/黙秘を破る）

- **必須3要素:** ①二人称（YOU/あなた） ②自分事の脅威 ③司法の線引き（最高裁判例で決着）。
- **強い束（優先）:** 第4修正＝令状・捜索・追跡・スマホ・押収・黙秘・私財没収。上位実績と一致。
- **弱い束（単体では避ける）:** 純・金融史（Madoff本編43再生・APV18%）。使うなら「あなたの年金がこう溶ける」等、自分事フレームに変換して初めて可。
- 1企画=1判例=1つの「あなたへの脅威」。テーマの被り素材も禁止（v2 `footage_diversity`）。

## 4. ファネル設計（Shorts 69%を登録に変換する）

現状の最大の穴。Shortsは**発見の入口**であって収益ではない（ShortsのRPMはほぼ0）。役割を固定する。

```
[Shorts 日次1本] ──フック→未解決の問い→ "全事件は本編で" ──▶ [本編 週1〜2本] ──earned CTA──▶ [登録]
        │  ・二人称の権利問題1本勝負                              │  ・11〜12分（実績band）
        │  ・終了画面＝固定の看板本編へ                            │  ・APV45%+ / 30s残存70%+
        │  ・固定コメントで問いを投下（コメント率↑）               │  ・感情ペイオフの後に具体CTA
        └─ 概要欄トップに本編リンク                               └─ 終了画面に次の本編＋登録
```

**Shorts側の必須（build_short系に反映）:**
1. 終了画面 or 明示CTAは **1つだけ**＝「続きは本編（チャンネル固定）で」。登録の直請いはしない。
2. 固定コメントに**問い**を1つ（例: "Would this hold up in your state?"）。コメント率をゼロから脱出させる。
3. 概要欄1行目＝本編パーマリンク。
4. 音量は終始一定（既存 `build_short_mix.py` の speechnorm+2パス静的-14 を継続）。

**本編側の必須（v2の該当GATEで担保、ここでは狙いのみ）:**
- フック0:00–8s（v2 row9）＝Shortで見た問いの「本編版・拡大」。
- earned CTA（v2 row10）＝感情ペイオフ直後に「あなたの見方が変わったら登録を」。
- 終了画面＝次の本編＋登録（回遊で関連流入を作る）。

## 5. 量産カレンダーと2年ロードマップ（条件付き・正直版）

**大前提:** 各Phaseの前進条件は「北極星をクリアしたか」。日付ではなく数字でゲートする。

| Phase | 目的 | 前進条件（これを満たすまで次に行かない） | 制作ペース |
|---|---|---|---|
| **0. 型の証明** | 本編1本を勝たせる | 本編1本で **CTR6%+ / APV45%+ / 30s残存70%+ / 1万再生** | 本編1本に集中＋日次Short |
| **1. 再現** | 型が偶然でないと示す | Phase0基準を **5本連続** クリア | 週1本＋日次Short |
| **2. スケール** | 量で伸ばす | 直近10本平均で **10万再生 / 登録転換10** | 週2本＋日次Short |
| **3. 拡大** | 収益化最大化 | 月間 **550万再生（収益化）** で月500万円到達 | 週2本＋日次Short＋横展開 |

**登録マイルストーン:** 2 → 1,000（Shorts収益化条件）→ 10,000 → 100,000 → **1,000,000**。
各段は「1本あたりの平均再生 × 登録転換 × 本数」で積む。飛び級はしない。

**月500万円の算数（握っておく現実）:**
- 月500万円 ≒ 月$33,000。本ジャンル英語・米国中心の長尺RPM ≒ $5〜8。
- → 必要な**収益化再生 ≒ 月550万回 ≒ 1日18万回**。**Shortsでは作れない。長尺のみが収益源。**
- 100万登録＋週2本（平均30〜50万再生）＋回遊するカタログ、で射程に入る。ただし**Phase0の型が動いた日から数え始める**。

## 7. CTR/インプレッション取得（Studio内部・要注意）

**確定事実（2026-07-04 実測）:** 公式 YouTube Analytics API は `impressions` / `impressionClickThroughRate` を**サポートしない**（"Unknown identifier" で拒否を確認）。CTRはStudio内部データのみ。

**方針（オーナー選択 2026-07-04）:** Studioのセッションcookieで内部エンドポイントから自動取得する。
**リスク明示（invariant 3 / rules 03・北極星「BANされない」）:**
- 非公式エンドポイント＝**規約グレー・仕様変更で壊れる**前提。自チャンネルの読み取り専用に限定。
- cookieは**機密**。`.gitignore` 済みのローカルファイルのみに保存し、コミット・ログ・スクショに出さない（invariant 3）。
- 書き込み・削除・設定変更は一切しない（読み取り専用）。

**実装ステータス:** 未完成（正確なペイロードはブラウザ実キャプチャが必要）。オーナーの1回だけの手順（DevTools→該当リクエストを "Copy as cURL"）を受領後、`scripts/yt_studio_ctr.py` として確定する。以降は全自動。
