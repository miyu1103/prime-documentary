# ショートから長尺へ送る唯一の経路 ―― 関連動画リンクの設定手順

**v001 / 2026-08-07 / 実測にもとづく**

---

## なぜこれをやるのか

2026-05-01〜08-06 の実データで、長尺12本の流入元を1本ずつ調べた結果がこれです。

```
views   REL   SUB  SRCH  SHRT   長尺
  251    91    19     8     0    Following the deposit rule（Hinders）
  183    82    39    22     0    He called safety pure waste（Titan）
  159     7   144     6     0    Police Can Stop and Frisk You
   90    90     2     2     0    Fifty years later the FBI（D.B.クーパー）
   69    58     0    10     0    He showed the officer the receipt
   68    79     4     1     0    Police Never Saw the Driver
```

**SHRT（ショート経由）が12本すべてで 0 です。**

同じ期間にショートは 5,134 回視聴されています。それでも長尺への流入は 1 件もありません。
導線が「弱い」のではなく、**成立していない**という意味です。

すでに実施済みの2つは、いずれも代わりになりません。

| 施策 | 実測 |
|---|---|
| 動画末尾の導線カード（サムネイル＋タイトル） | 静止画。ショートUIではリンクとして扱われない |
| 固定コメントのURL（48本に設置済み） | クリックがあれば `EXT_URL` に出るはずだが、3か月で36回のみ |

YouTube がショートから長尺へ視聴者を送る**公式の仕組みは「関連動画」だけ**で、これは
**YouTube Studio でしか設定できません。Data API にも Analytics API にも該当機能がありません。**
つまり手作業以外に方法がありません。

---

## 設定手順

### 1本あたりの操作

1. 作業リストの URL を開く（`https://studio.youtube.com/video/<ショートのID>/edit`）
2. 左メニュー **「詳細」** が開いた状態にする
3. 下へスクロールし **「すべて表示」** をクリック（既定では折りたたまれています）
4. **「関連動画」** の欄を探す
5. リストから対象の長尺を選ぶ。見つからないときは、リストの検索窓に
   **作業リストの `longform_video_id` を貼る**（タイトルより確実です）
6. **「保存」**

所要は 1 本あたり 20〜30 秒、54 本で 20〜30 分です。

### 注意点

- **非公開の長尺は選べません。** リストに出てこない場合、その長尺がまだ公開予約中です。
  作業リストの「まだ設定できないもの」に該当します。長尺が公開されてから設定してください。
- **公開予約中のショートにも設定できます。** 予約済み（private + publishAt）の状態でも
  関連動画は設定でき、公開時にそのまま有効になります。
- 保存後、Studio の表示が変わらないことがあります。**ページを再読み込みして確認**してください。

## 効果の測り方

設定してから **7日後** に、同じクエリで再測定します。

```
py -3.11 scripts/yt_funnel_analytics.py 2026-08-07 <7日後>
```

判定は単純です。**長尺の `SHRT` 列が 0 から動くかどうか。**

- 動いた → 関連動画リンクが唯一の有効経路だったと確定する
- 動かない → 別の要因（ショートの内容、長尺のサムネイル、そもそもの需要）を疑う

現在 0 なので、**1 でも入れば因果が確定します。**これは珍しく、きれいに切り分けられる実験です。

## この作業を止めないこと

いま予約済みの 20 本、および完成在庫 96 本は、すべてこの設定をしないと長尺に 1 回も流れません。
**ショートを何本作っても、この 30 分をやらない限り登録者は増えません。**

長尺の 1000 再生あたり登録は 3.92、ショートは 0.97 です。登録を増やす経路は長尺側にあり、
そこへ人を送る唯一の手段がこの設定です。
