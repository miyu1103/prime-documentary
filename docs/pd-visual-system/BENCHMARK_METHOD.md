# Benchmark Shot Analysis Method

## 目的

チャンネルのロゴ、配色、フォント、固有セット、素材、音楽をコピーせず、成功している映像の**機能**をショット単位で観察します。

## 最小サンプル

- 参考チャンネル: 最低3、推奨5
- 各チャンネル: 最低3動画
- 各動画: 最低5ショット
- 合計: 最低45ショット、推奨75ショット

## 記録対象

1. ショット開始・終了タイムコード
2. ナレーション上の役割
3. visual question
4. visual verb
5. start state / end state
6. 主要レイヤー
7. カメラの開始・終了
8. テキスト出現順
9. 音響イベント
10. 視線の主対象
11. 再利用可能な抽象原理
12. コピーしてはいけない固有要素

## 法的・倫理的境界

- 合法的な視聴と手動観察を前提とする。
- 映像、音声、字幕、画像を素材として保存・再配布しない。
- スタイル名をコンポーネント名にしない。
- ショット順やタイミングをそのまま複製しない。
- 一つのチャンネルからではなく、複数の原理をPDの目的へ翻訳する。

## 採用判断

各観察から、次の一文を必ず作ります。

> このショットの価値は「見た目」ではなく、視聴者の理解を ______ から ______ へ変えた点にある。
