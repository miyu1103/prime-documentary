# Source, Truth, and Disclosure Policy

## Source types

1. `verified_evidence`: 実際の判決文、記録、写真、証拠。
2. `documentary_source_media`: 事件・人物・場所と直接関係し、真正性を確認した映像。
3. `licensed_broll`: 一般的な状況説明用の正規ライセンス素材。
4. `illustrative_animation`: 制度・因果・比較を説明する非写実図解。
5. `three_d_reconstruction`: 既知事実に基づく簡略3D再現。
6. `ai_generated_broll`: 特定事件の事実を断定しない雰囲気用生成映像。
7. `ai_reenactment`: 実際の人物・場所・出来事を表す生成再現。

## Truth status

- `verified`: 一次資料または信頼できる複数資料で確認。
- `corroborated`: 複数資料で一致するが一次資料未確認。
- `unverified`: 未確認。公開用の事実表示に使わない。
- `not_applicable`: 説明図・抽象背景など事実主張を担わない。
- `prohibited`: 誤認、捏造、権利侵害リスクにより使用禁止。

## Disclosure decision

写実的なAIまたは大幅改変映像が、実在人物、場所、出来事として誤認され得る場合は、YouTube上のAI利用開示と画面内ラベルの両方を検討します。

## Non-negotiable rules

- AIで判決文、新聞、警察文書、証拠写真を作らない。
- 実在人物が言っていない発言をしたように見せない。
- 再現映像を実映像と同じラベル・色・タイムコードで見せない。
- ライセンスと出典が不明な素材を本番へ進めない。
