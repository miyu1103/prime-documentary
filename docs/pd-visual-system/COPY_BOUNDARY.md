# P02 COPY BOUNDARY — 採用する原理 / コピー禁止の表皮

- Phase `P02` / 2026-07-12 (JST)
- 目的: 参考チャンネルから**採用してよい機能原理**と、**絶対に複製しない固有表皮**を分離する（CLAUDE rule / ブリーフ§9）。

## 採用してよい（機能・原理）
- 物語構造（危機→利害→逆転→章末の引き）
- 情報を一つずつ積み上げる視線設計
- 調査素材を地図・関係図・時系列へ変換する考え方
- 要所へ予算集中、他は簡潔
- 山場のみ空間再現/立体カメラ
- 音の役割分担（ナレ最優先・BGMダッキング・要所SFX・環境音ベッド）

## コピー禁止（固有の表皮）
- ロゴ、チャンネル名、固有フォント
- 固有配色（他chのブランドカラー）
- 固有セット/スタジオの見た目そのもの
- 他chが使った具体的素材（映像・画像・音源）
- **ショット順・タイミングのそのままの複製**
- スタイル名をコンポーネント名にしない（例: 他ch名をコンポーネント名に使わない）

## 実務ルール
- PDのブランド（黒/紺/エレクトリックブルー/シルバー/金・Impact系見出し）を正とする（VIDEO_RULES §7）。
- 複数チャンネルの**原理を混ぜて**PD目的へ翻訳（一つのchを丸ごと真似ない）。
- 参考動画のフレーム/音/字幕/画像を**素材として保存・再配布しない**。
