## 2. なぜ必要か（数字）

ビルダー `build_case_film_generic.py` には2つの構造アサーションがあります。

* カットは **150本以上**
* そのうち **62%以上が「動く素材」**（factory の実写 か motion の i2v）

EP77 の動く素材はいま **実写42本＋motion 0本**。実際に回すとここで止まります。

```
$ py -3.11 scripts/build_case_film_generic.py --config episodes/_planning/EP77_keybridge_filmconfig.v001.json --dry-run
keybridge: too few cuts 61 (plan={'factory': 42, 'motion': 0, 'still': 19,
                                  'pools': {'factory': 42, 'motion': 0, 'still': 115, 'people': 21}})
```
receipt: `runs/qc/keybridge_builder_shortfall.v001.txt`

27分を 4.6秒刻みで埋めるなら実際は約350カット必要で、reuse≤2 なら**動く素材が約110本**要ります。

```
いま      実写 42 + motion   0 = 42本  → 最大135カット（150に届かない）
納品後    実写 42 + motion 115 = 157本 → 314カット（足りる）
```

これは後付けの要求ではありません。`episode_spec.v001.json` の `distinct_video_assets: 252` は
**プレートを動かす前提でないと足し算が合いません**（motion 115 + factory 42 + stills 94 = 251）。
最初からそう設計されていて、その工程だけが未実行という状態です。

**実写を増やす道は塞がっています。** 候補181本を全画面で1本ずつ読んで採用32本＝歩留まり18%。
110本を実写だけで作るには約600本の目視が要り、しかも棚の該当クエリ空間はほぼ使い切りました
（12,054本が他話で使用済み除外、3,413本が過去の却下 verdict で除外）。

## 4. この話数の制約（`episode_spec.v001.json` より）

* 舞台は **2024–2026年のボルチモア（USA）の夜**。作り出す動きも同じ時代・同じ場所であること。
* **`forbidden_subjects` に載っているものを生成しないでください**（124語）。特に:
  遺体・犠牲者・葬儀、**橋が崩れる瞬間**、**船が橋にぶつかる瞬間**、子ども、
  読める文書、ウォーターマーク、生成物であることを示すマーク、
  および外国の地名（japan / china / taipei / moscow / paris / london / venice / new york / europe …）。
* **i2v は「中身を変えずに生かす」範囲で。** 霧が流れる、水面が揺れる、光がちらつく、
  カメラがわずかに寄る——この範囲です。**新しい被写体を出さないでください。**
  実測された事故: 何も無いコンクリート壁にスーツの男が生成された／路肩に女性の顔が生成された。
