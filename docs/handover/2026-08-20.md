## 1. The drive is not coming back

in the same port and cable, twice. The plain T7 in that same proven-good port and cable never
enumerates — no volume, no disk, no USB mass-storage device, no PnP event in the system log.
The LED lights, so it takes bus power; nothing answers on the data lines. Its controller is
gone, and the T7 encrypts in the controller, so chip-off recovery is not realistically
available. **Do not throw the drive away** — it is the only remaining option if something on it
turns out irreplaceable.

`assets/asset_manifest.v001.json`, every past episode's AI plates / i2v masters / narration

CC-BY / CC-BY-NC, which is why the reindexer marks them `review_required` rather than clearing

## 2. The shelf's memory was rebuilt — and this session's own instrument lied twice about it

`scripts/reindex_archive_shelf.py` (new) walks D:/E:/F:, parses `<source>__<id>__<slug>`,
derives the licence from the source's terms, and writes the per-source JSONL the ledger reader
expects. `shelf.py` now points at `E:\pd-archive\_ledger`; `shelf_rows()` returns **59,650
rows**.

Two lies, both mine, both caught by measuring rather than by reasoning:

1. **`isalnum()` cost 24,964 files.** The ingest writes `pixabay_extra__i_10240499__…`, and an
   underscore is not alnum, so every one fell to `unattributed` and was recorded as
   licence-unknown. I reported to the owner that ~10,000 videos could never be cleared. Reading
   all 24,364 rows showed **not one was genuinely unknown** — all were Pixabay, whose licence is
   blanket commercial. Fixed; the ledger now carries them as `pixabay_extra` / `pd`.
2. **A term measured against its own storage path.** `measure_shelf_for_episode.py` (new)
   reported `archive` at 1,928 hits because every row lives under `D:\pd-archive` and separator
   normalisation turns that into "pd archive". Same class as the process check that matched its
   own signature. It now matches title + filename only.

   global stock shelf for a *place*. `animal` was never going to return a Butte County cow.
