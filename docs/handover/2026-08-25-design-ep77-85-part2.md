## 4. 残り1件は設計の穴ではない — 組み立てが物理的にできない

```
$ py -3.11 scripts/build_case_film_generic.py --config .../EP77_keybridge_filmconfig.v001.json --dry-run
keybridge: too few cuts 61 (plan={'factory': 42, 'motion': 0, 'still': 19,
                                  'pools': {'factory': 42, 'motion': 0, 'still': 115, 'people': 21}})
```
（receipt: `runs/qc/keybridge_builder_shortfall.v001.txt`）

ビルダーの構造アサーションは **カット150本以上**かつ**映像比 62%以上**。いま61本しか作れない。
27分を 4.6秒刻みで埋めるなら実際には約350カット必要で、reuse≤2 なら**映像素材が約110本**要る。
**いま42本。** Root.tsx の登録は `remotion/src/data/keybridge_film.json` を import するので、
film.json が作れない以上、登録するとバンドル全体が壊れる。だから**あえて登録していない**。

**これは EP77 固有ではない。**

| | factory | plates | motion |
|---|---|---|---|
| 77 keybridge | 42 | 115 | **0** |
| 78 colgan | 66 | 166 | **0** |
| 79 alaska261 | 51 | 198 | **0** |
| 80 concordia | 0 | 185 | **0** |
| 81 station | 0 | 188 | **0** |
| 82 valdez | 0 | 183 | **0** |

`episode_spec` の `distinct_video_assets: 252` は、**プレートを i2v で動かす前提でないと足し算が合わない**
（115 motion + 42 factory + 94 stills = 251）。つまり最初からそう設計されている。
**i2v は別スレの担当**なので、ここで止めて報告する。宣言値は下げていない。

棚をもう一周しても埋まらない。実測18%の歩留まりで110本を作るには約600本を全画面で読む必要があり、
しかも今回の2ラウンドで「港・夜道・書類・水」のクエリ空間はほぼ使い切っている
（12,054本は他話で使用済みとして除外され、3,413本は過去の却下 verdict で除外されている）。
