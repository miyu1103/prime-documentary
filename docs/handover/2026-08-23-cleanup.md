## 3. The mechanism

`scripts/check_doc_contradictions.py`. Seven rules, each one a contradiction that actually
existed, plus broken-link detection, over 98 binding documents.

```
py -3.11 scripts/check_doc_contradictions.py          # 0 contradictions today
py -3.11 scripts/check_doc_contradictions.py --demo   # 6 of 6 rules fire on bad text
```

Wired into `HANDOVER.md`'s opening commands and `PD_CANON` §11. **When a new contradiction is
found, add a rule there — not a paragraph to `docs/`.** A line that declares itself a
correction (`訂正`, `SUPERSEDED`, `記録`, `廃止` …) is exempt, which is how a document records
what it used to say without tripping the rule forbidding it. `--demo` proves that exemption
works, or every corrected line would become a permanent false alarm.

## 4. The tidy, and the three exclusions that mattered

`scripts/tidy_repo_root.py` moved 630 things. **Nothing was deleted.** Root 455 → **78**,
`scripts/` 1,046 → **832**.

The first plan would have caused damage in three ways, all found by attacking it before
running it:

1. **Seven files that look like logs are not logs.** `out_finish_<slug>.log.satisfied` is the
   marker saying an episode's finisher completed; `handover_snapshot.py` and
   `_finish_episode.sh` read it. Moving them would have told the machine seven finished
   episodes were unfinished, and a finisher run is ~3 hours. `out_prepare_done.txt` is the
   same shape for `prepare_for_scheduling.sh`.
2. **Six "unused" scripts are imported by module name.** The unused list was built by
   searching for the filename WITH its extension; Python imports without one, so
   `import sdxl_quality_profiles` was invisible.
3. **A lock is not a log.** Five scripts depend on `out_pdrun_*.lock`.

**The instrument that found (1) also lied**: it reported 36 hits and 34 were a variable named
`out_path`. That is the eleventh entry in PD_CANON §7's list of instruments that lie, and it
was this session's own.

Undo is one command and was **proven by round-tripping a file**, not asserted:
`py -3.11 scripts/tidy_repo_root.py --undo-from runs/_attic/UNDO_tidy_20260823.json`.
The `--apply` run had advertised that flag before it existed; it was implemented and tested
immediately.

**Proof nothing broke:** `handover_snapshot.py` and `check_queue_will_stall.py` produce
byte-identical output before and after, except the clock and 0.1 GB of free disk.

## 5. After Effects, from EP77

`decisions/0011` accepted AE from EP77 and the owner clarified the same day: **used heavily,
and the design stage is what has to work first.** So `ae_beats` is now part of the episode
contract, required from EP077 by `check_episode_spec.py`.

- **≥12 beats, ≥1 per act, ≥90 s on screen.** Floors from measurement: the median spec
  declares 8 acts at 13–17 figure beats (104–136), so twelve is about a tenth of them and
  **6–12× the previous standard** (PD_CANON §6's "one or two kinetic beats mid-film").
- Nine declared kinds. Cuts, captions, bookends and the 38 figure kinds stay in Remotion.
- **Every beat needs a `source`** — the ledger row or script line its headline came from. An
  AE card states a fact on screen and falls under `factual_support` like a title.
- `tests/test_ae_beats_design_gate.py`: 11 cases, every floor broken on purpose, all green.
  All 26 existing specs re-validated; the only two failures (`lacmegantic`, `uri`) are a
  pre-existing `_people_plates_note` extra property and **predate this work** — those two
  specs are invalid right now and their thread should know.

**What it does not do:** it never sees whether an AE card rendered. `decisions/0011` still
requires a pixel-reading verify before the film json is built. A green design is not a
rendered beat.
