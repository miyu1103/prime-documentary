## 2. 他の話数にも効く実測（ここが本題）

### 2.1 題材選定のルールが1つ、実測で置き換わった

`TOPIC_PIPELINE.v005` の **「definitive現職（3M+再生）がいる題材は却下」は使えない。**
`TOPIC_POOL_500.v001.md` §2b（8/23）の **F1**: 有名題材はCTR **2.24% vs 1.52%（+47%）**、
そしてPDの最良2本（OceanGate 3.14% / D.B. Cooper 2.37%）は**最混雑題材の上に立っている**。
この却下ルールを守った結果、**737 MAX（需要中央値131万・盤上1位）が7月から捨てられたままだった。**

→ 今後の題材会議では「競合が強い」を却下理由にしない。**却下理由は需要の欠如と、
うちの視聴者（米55+男・92.5%男）が名前を言えないこと**の2つ。

### 2.2 需要の中央値だけで決めると事故る

「冤罪×補償ゼロ」は中央値 **193万**で盤上最大に見えた。上位行を開いたら A&E の釈放リアクション
切り抜き（29M・3分）で、**前提そのものの動画は391視聴と163視聴**だった。
逆に「有名だから需要がある」も嘘で、**Flint水危機は中央値 14,979**。

→ `topic_demand_probe.py` の結果は**必ず上位行を読んでから**採用する。中央値は入口であって答えではない。

### 2.3 タイトルの実測ルール（全話に効く・出典つき）

| ルール | 実測 |
|---|---|
| 検索される**事件名**を入れる（先頭70字以内） | impressions 約2倍（690 vs 366） |
| **権力を主語に**開く（Boeing / The Court / The FAA…） | CTR **2.12% vs 1.47%** |
| **2文構成**（前提。裏切り。） | CTR **1.79% vs 1.25%** |
| died / killed / deaths を**書かない** | 競合 0.06×・自CH 1.09% vs 1.68% |
| コロン・emダッシュ・疑問形・you・ALLCAPS語を避ける | 0.34× / 0.43× / 0.83× / 0.44× / 0.45×（長尺のみ。ショートは逆） |
| 60字超を恐れない | 自CH 81字以上で CTR 1.92% |

**律速はCTRではなくインプレッション**（中央値 23.7 imp/日）。だからタイトルの第一の仕事は
「検索される語を持つこと」で、次が「クリックされること」。

### 2.4 サムネは**320pxで**選ぶ

原寸で最も美しかった板（AoAセンサーの接写）は320pxで**何の物か読めず**、黒地にオレンジ1点の
地味な板が最強だった。TMIの記録計・会見場は320pxで灰色に潰れた。
→ プレート選定も合成後の確認も、**必ず320px縮小シートを作ってから**。原寸に決定権を与えない。

### 2.5 `check_thumb_subject_luma` の FAIL は直さない

winnerスタイル（ライブ最高CTR **4.48%** の実測採寸）は、このゲートの
**文字150px床・輝度60床を意図的に満たさない**（勝者実測94px・暗い画）。
緑にするために明るく大きくすると、**実測で負けている側の見た目に戻る**。
合成9枚中8枚がFAILだが正常。逸脱として記録する運用にした。

### 2.6 機械検査は「何が写っているか」を見ない

30枚の受入で、解像度・比は全数PASSだったが、**1枚は5分割コラージュ**だった。
これは目視でしか捕まらない（i2vレーンの `qc_i2v_tail_vs_plate.py` の指摘と同じ性質）。
→ 画像納品は**必ずラベル付きコンタクトシートを1枚作って人が見る**。

## 3. 進め方についての反省（メインスレにも同じ危険がある）

オーナーに「その3つがベスト？」と**3回**聞かれ、**3回とも本物の欠陥**が出た
（既存話数との被り／古いルールの適用／未計測の大物）。原因は「調べ尽くした感」で停止したこと。
**結論を出す前に、①未計測空間の列挙とゼロ確認 ②既存全成果物との被り照合（書く前に）
③採点軸の機械実行（目視で代替しない）** を書き出す。この3つが揃うまで「ベスト」と言わない。

自作の監査スクリプトが**自分に甘かった**実例もある（Katrinaの検索語判定が "New Orleans" を許容）。
チェッカーは**わざと落ちる入力で1回試してから**使う。
