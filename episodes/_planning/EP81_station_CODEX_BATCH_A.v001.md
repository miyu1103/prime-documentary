**③ 実在の社名・ロゴ・会社色を一切入れないでください。** EP79 では、禁止語に書いてあったのに**実在航空会社のロゴが3枚**出ました。EP80 でも**煙突の色**が出ました。**消防車・救急車・パトカーは無地**にしてください（S115 / S123 / S124 / S125 / S126 / S163 に明記済み）。

**⑤ 人物は後ろ姿かシルエットのみ。** `P` を付けた20枚が該当します。顔が判別できたら不合格です。

**⑥ 2003年のロードアイランドです。** 車・携帯電話・服装を2003年のものに。**道路脇の小さな木造の店**で、都会の大箱ではありません。
