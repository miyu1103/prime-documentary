## なぜ止まっているか

TikTokの画面がこう言った:

```
コンテンツの簡易チェック  本日のチェック回数の上限に到達しました。明日またお試しください。
```

音楽の著作権チェックは緑のまま。**コンテンツチェックだけがアカウント単位・1日単位で上限**。
待っても通らない。スクリプトは `CHECK_LIMIT_REACHED` を返してバッチ全体を止める。

**この制限を回避しないこと。** フォロワー0の新規アカウントが1晩に100本消して100本上げるのは、
この制限が捕まえようとしている動きそのもの。このチャンネルはBANを吸収できない。

## 再開コマンド

```bash
cd /c/temp/studio_auto
node start_chrome.js          # 専用プロファイル。初回だけ手動ログインが要る
sleep 18
node tt_batch_clean.js 2026-08-11 0     # 開始日と、その日に既に埋まっている枠数
```

**1日20本程度を上限にする。** 上限に当たったら勝手に止まるが、当たる前に止めるほうが安全。
翌日は開始日を進める（例: 8/13から埋めるなら `2026-08-13 0`）。

## 覚えておくこと

- **投稿後にカバーは変えられない。** 予約済み・公開済みとも編集アイコンは全部 `cursor: not-allowed`。
  だから消して上げ直すしかない。
- **予約中でもカバーはプロフィールに出る。** 出ていなければカバーが乗っていない。
  「予約中は動画フレームになる」というのは誤りだった（8/10 10:00のタイルで確認）。
- 削除ツールで予約済みを見分けるときは日付を見ない。日付は公開済みの行にも出る。
  編集アイコンが無効かどうかで判定する（`delete_posts_tiktok.js` は修正済み）。
