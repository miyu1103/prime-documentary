# 縦型プレート生成仕様 v001 — Codex発注契約（2026-08-01）

**目的**：ショート（1080×1920）用の静止画を、切り落としゼロ・偽文字ゼロ・暗すぎゼロで作る。
**適用**：`short82`以降のすべてのショート。既存の横長ライブラリ（EP01〜EP30系）は縦では使わない。

---

## 0. なぜこの仕様が要るか（実測）

2026-08-01、EP01の既存プレートで `short82` を試作し、書き出したファイルを独立測定した結果：

| 症状 | 実測値 |
|---|---|
| 元画像が 2048×1152（16:9） | 縦9:16に中央切りすると **横幅の31.6%しか残らない** |
| 結果 | 手錠・法廷ベンチ・鉄格子が全部フレーム外。青い縦縞に見える |
| 平均輝度 | **29.1**（1294フレーム中834＝64%が輝度25未満） |
| 偽の英文字 | `SPN-0007_03` "THE IS COOFESSIFB IONS IONV"、`SPN-0016_06` "PRCRETY OBSCROVIL"、`SPN-0018_06` "CHIACROSCIRA" |

3つとも、**縦で生成すれば全部消える**問題である。

---

## 1. 必須ルール（1つでも破ると使えない）

### R1. サイズは 1080×1920 ちょうど
16:9で作って切るのは禁止。生成が 896×1600 等でも構わないが、**納品は 1080×1920 にリサイズ済み**であること。

### R2. 画面の使用禁止帯
`Short.tsx` が上に重ねる要素の座標（実装値）：

| 帯 | y座標 | 何が乗るか |
|---|---|---|
| 上部 | **0 – 560** | ペルソナマーク(y96) ＋ テロップ(y180-560, 96px) |
| 中下部 | **1000 – 1320** | 字幕（金枠・58-66px） |

→ **主役は y560–1000 か、y1320 以下に置く。** この2帯は「静かな面」であること（空・壁・煙・床など）。

### R3. 読める文字を一切入れない
書類・看板・時計文字盤・本の背・車のナンバー・バッジの刻印——すべて無地／判読不能に。
プロンプトに毎回 `blank and unreadable` を明示する。ネガティブ任せにしない（EP01はネガティブがあっても偽文字が出た）。

### R4. 実在人物の likeness を作らない
シルエット・後ろ姿・手元・物のみ。顔を正面から作らない。
（CLAUDE.md 不変条項11。実在の事件を扱うため、これは法務リスクである）

### R5. ★ 光源を名指しし、「点いている」と書く ★
**これが一番外しやすい。** 2026-08-01の実測：

- 「無人の取調室、頭上に円錐ランプ」→ **平坦な緑がかった昼光。ランプは消灯。ドラマゼロ**
- 「鉄格子の向こうに立つ男のシルエット、背後から強い廊下光」→ **狙いどおり。煙・逆光・強コントラスト**

差は「照らす対象があるか」ではなく「**光源が明示され、それが唯一の光源だと書かれているか**」。

→ 全プロンプトに必ず入れる：
`lit ONLY by <名指しした光源>, which is switched on and is the only light in frame`

### R6. 暗さの下限
**平均輝度 45–70** を目標。暗い雰囲気は「影を深く」で作り、全体を落として作らない。
主役の面は必ず見えること（スマホの屋外視聴が前提）。

### R7. 納品形式
- PNG / sRGB / 1080×1920
- 連番＋**1枚ごとに「何を写したか」の1行**（ファイル名だけでは照合できない）
- **ラベル付きコンタクトシート**を各バッチに1枚（人間が目視選別するため。過去にプロンプトIDで選んで中身が全然違った事故が3件ある）

## 2. 共通スタイル文字列（検証済み・全プロンプトの末尾に付ける）

```
, vertical 9:16 composition, cinematic film still, anamorphic, 35mm grain, night,
ONE hard practical light source which is switched on and is the only light in frame,
strong chiaroscuro, the subject clearly lit against deep shadow, smoke and volumetric
light shafts, desaturated amber and steel blue, shallow depth of field, photorealistic,
no lettering, no signage, no readable text
```

ネガティブ（SD3.5で使用中・Codexでも同等に）：
```
cartoon, anime, illustration, 3d render, cgi, plastic skin, waxy, deformed, extra fingers,
bad hands, blurry, lowres, jpeg artifacts, oversaturated, text, watermark, signature
```

**時代設定は事件ごとに差し替える**（`1963 America` / `2011 Detroit` など）。ここを固定すると全話同じ絵になる。

## 5. プロンプト台帳の場所

`episodes/_planning/vertical_plates/<slug>_shortNN.v001.json`

```json
{
  "short_id": "short83",

  "angle": "彼は鉛筆で最高裁に手紙を書いた。全員一致で勝った。",
  "era": "1961 Florida",
  "plates": [
    {"n": 1, "role": "hook", "subject": "…", "prompt": "…"},
    ...
  ]
}
```

`role` は `hook / body / payoff / loop` のいずれか。`subject` は日本語1行（目視選別用）。

## 6. 受け入れ検査（納品後、私が機械で回す）

| 検査 | 合格条件 |
|---|---|
| 解像度 | 1080×1920 ちょうど |
| 平均輝度 | 45–70 |
| 最暗部の占有 | 輝度25未満のピクセルが画面の50%未満 |
| 使用禁止帯 | y0-560 と y1000-1320 の分散が低い（＝静かな面） |
| 文字検出 | OCRで読める文字列が0件 |
| 目視 | ラベル付きコンタクトシートで全数確認 |

不合格の枚数と理由を返すので、その分だけ再生成してもらう。
